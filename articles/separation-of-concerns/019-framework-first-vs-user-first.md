# Framework-first or user-first: which end do you build from?

**Reader question:** Should a project start from the framework or from the user?

## Outline

- **Problem:** picking the framework first lets its defaults decide what users get.
- **Native solution:** start from what the user sees and does, then pick the least powerful tools that deliver it (his two diagrams, redrawn).
- **Link out:** MDN guide to what frameworks do.
