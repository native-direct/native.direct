# Forms done right: fieldset, legend and label

**Reader question:** How do I structure an accessible form?

## Outline

- **Problem:** forms without groups and labels confuse screen readers and mouse users alike.
- **Native solution:** fieldset groups, legend names the group, label names each control.
- **Link out:** MDN fieldset and the form-structure guide.
