# Div-less HTML: what to use instead of div and span

**Reader question:** What replaces div and span?

## Outline

- **Problem:** div and span say nothing to browsers, screen readers or the next developer.
- **Native solution:** pick the element that names the job (header, nav, main, section, article, aside, footer, figure, ul).
- **Link out:** MDN element pages.
