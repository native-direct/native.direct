# Accessibility is not usability

**Reader question:** If my site passes an audit, is it usable?

## Outline

- **Problem:** teams treat a passed audit as done.
- **Native solution:** his line: access is where usability starts, not where it ends; test real tasks with real assistive tech.
- **Link out:** MDN WCAG guide and glossary.
