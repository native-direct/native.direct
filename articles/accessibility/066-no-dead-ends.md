# No dead ends: every empty or error state needs a way out

**Reader question:** What should every error or empty page offer?

## Outline

- **Problem:** error pages and empty lists that leave users stuck.
- **Native solution:** every empty, error or blocked state names what happened and offers one next step.
- **Link out:** MDN :empty (for CSS-shown empty states).
