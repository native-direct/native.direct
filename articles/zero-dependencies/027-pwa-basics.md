# PWA basics: a website that installs like an app

**Reader question:** What does a PWA give users?

## Outline

- **Problem:** teams build separate desktop or store apps for what a website can do.
- **Native solution:** a manifest plus a service worker make the same site installable and offline-capable.
- **Link out:** MDN PWA guide and manifest reference.
